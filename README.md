# Обод маҳалла

Тошкент шаҳри электр тармоқлари мониторинги (Django). Учта манба бирлаштирилади (`data/`):

| Файл | Мазмуни | Нимаси олинади |
|---|---|---|
| `Обод махалла.xlsx` | 205 ТП нинг техник маълумотлари | ТП маълумотлари (туман/маҳалла номлари нотўғри бўлган) |
| `TrLoadProfileReport(2).xlsx` | Тизим ҳисоботи — барча ТП (12 277 қатор) | Туман (РЭС), подстанция, фидер, кучланиш, ток, cos φ, юкланиш |
| `илова 2., 138 млрд (2) (2).xlsx` | 2027 йил «Обод маҳалла» дастури | Маҳаллалар, уларнинг ишлари, нархлари ва ТП рақамлари |

Натижа: `data/Обод маҳалла — бирлаштирилган маълумотлар.xlsx` (Туманлар, Маҳаллалар, ТП лар,
Дастур ишлари, Тузатишлар варақлари; жамлар формулалар билан).

## Ишга тушириш (Windows)

```powershell
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # фақат биринчи марта; SECRET_KEY ни ўзгартиринг
python manage.py migrate
python manage.py import_excel        # уч манбани бирлаштириш, базага юклаш ва Excel яратиш
python manage.py createsuperuser
python manage.py runserver
```

- Сайт: http://127.0.0.1:8000/
- Админ: http://127.0.0.1:8000/admin/

## Интерфейс

Бир бетли, экранга тўлиқ сиғадиган интерфейс (бет пастга айланмайди). Чапдаги меню орқали бошқарилади:

1. **Бош саҳифа** — шаҳар бўйича умумий кўрсаткичлар (туманлар йиғиндиси), туманлар графиги, ТП ҳолати ва дастур ишлари таркиби.
2. **Туманлар** — 12 туман рўйхати; танланган туман маълумотлари ва маҳаллалари.
3. **Маҳаллалар** — 120 та дастур маҳалласи: кўрсаткичлар, ТП лари ва мақсади.
4. **Трансформаторлар** — 801 ТП (дастурдаги + Обод файлидаги): филтр (туман, ҳолат, манба), таҳлил ва барча маълумотлар.
5. **Мақсадлар** — 120 мақсад: 2027 дастуридаги ишлар, бюджет, йўналишлар ва натижалар.

Клавиатура: `/` — қидирув, `↑ ↓` — рўйхатда танлаш.

## Таҳлил қоидалари

- ТП тоифаси юкланиш бўйича: 0–50% — яшил, 50–60% — сариқ, 60% дан юқори — қизил.
- Кучланиш меъёри: 218,5–241,5 В (230 В ±5%), чегара 207–253 В (ГОСТ 32144-2013).
- Истеъмоли манфий/нол ТП лар «ҳисоб хатоси» деб белгиланади ва йиғиндиларга қўшилмайди.
- Туман — тизим ҳисоботидаги РЭС бўйича; маҳалла — 2.1-иловада ТП рақами шу маҳалла ишларида тилга олинганига қараб.
- Обод файлидаги ТП лар тизим ҳисоботидан ТП рақами + истеъмолчилар + қувват + кунлик истеъмол бўйича топилади.
- Кучланиш фазалари тизим сарлавҳалари бўйича (L1=А, L2=Б, L3=С).
- Мақсадлар — 2.1-иловадаги ҳақиқий ишлар (`apps/energy/goals.py`); устуворлик ТП ҳолати ва бюджетдан.

## Railway'га жойлаш

`railway.json` ҳар ишга тушишда: `migrate` → `collectstatic` → `import_excel --no-excel` → `gunicorn`.
База ҳар деплойда `data/` даги Excel файллардан қайта тўлдирилади.

Railway → Variables: `SECRET_KEY` (узун тасодифий матн). `DEBUG` бермаслик (ёки `False`).
Домен ва HTTPS созламалари автоматик (`RAILWAY_PUBLIC_DOMAIN`).

**Маълумот янгиланганда:** `data/` даги Excel файлни янгисига алмаштиринг (номи ўзгарса ҳам бўлади —
«TrLoad», «илова», «Обод» сўзлари бўйича топилади), кейин `git add data && git commit -m "..." && git push`.
Railway ўзи қайта деплой қилади ва сайт янги маълумотни кўрсатади.
