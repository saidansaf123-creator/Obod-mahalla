# Обод маҳалла 2027

Тошкент шаҳри «Обод маҳалла» дастури доирасида электр таъминоти ишлари мониторинги (Django).

**Ягона манба:** `data/Обод_махалла_2027.xlsx` — манзилли дастур (12 туман, 96 маҳалла, 389 иш,
110 ТП секцияси). Сайтдаги барча маълумот шу файлдан олинади.

## Ишга тушириш (Windows)

```powershell
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # фақат биринчи марта
python manage.py migrate
python manage.py import_excel        # файлни ўқиб, базани тўлиқ янгилаш
python manage.py createsuperuser     # админ панел учун
python manage.py runserver
```

- Сайт: http://127.0.0.1:8000/
- Админ (ижро маълумотларини киритиш): http://127.0.0.1:8000/admin/
- Тозаланган Excel: http://127.0.0.1:8000/export.xlsx

## Маълумотни янгилаш

`data/Обод_махалла_2027.xlsx` ни янгисига алмаштиринг (номи «Обод» сўзи билан бошланса бўлди), кейин
`python manage.py import_excel`. Серверда эса файлни GitHub'га push қилиш кифоя — Railway қайта деплой
қилади ва `import_excel` ўзи ишлайди. Админ панелда киритилган ижро (амалда) қийматлари иш матни
ўзгармаган бўлса сақланиб қолади.

## Админ панели (сайт ичида)

- Кириш: сайтдаги умумий қидирув майдонига махфий сўзни ёзинг (сўз фақат администраторга айтилади),
  кейин паролни киритинг (Railway'да `ADMIN_PANEL_PASSWORD` орқали ўзгартириш мумкин).
- **Ижро киритиш** — ишлар рўйхати (маҳалла, мақсад, маблағ, ижро %). Ишни танлаб, бугунги бажарилган ҳажм ва
  ўзлаштирилган маблағни киритасиз; «Қолганини бажарилди» тугмаси ишни тўлиқ ёпади. Ҳар бир ёзув журналга тушади.
- **Ижро журнали** — барча ёзувлар, кунлик ўзлаштириш графиги, ёзувни ўчириш (жамлар қайта ҳисобланади).
- **Excel юклаш** — янги манзилли дастур файли (шакли бир хил). Файл текширилади, база янгиланади, журнал
  янги ишларга қайта боғланади; файл базада сақланади (охирги 10 таси).
- Админ маълумот киритаётганда ёки файл юклаётганда бошқа фойдаланувчиларда анимацияли чақмоқ билан
  «Маълумотлар ўзгартирилмоқда» ойнаси чиқади; тугагач сайт уларда ўзи янгиланади (ҳар 3 сонияда текширилади).

## Файлни ўқиш қоидалари

- Туман қатори — A устунида рим рақами; иш қатори — A устунида тартиб рақами.
- Бир иш ТП нинг ҳар бир секцияси учун алоҳида қаторда, ҳажм ва нарх такрорланган ҳолда келади —
  **иш бир марта ҳисобланади**, секциялар ишга бириктирилади. Шунинг учун сайтдаги жами
  (210 507,55 млн сўм) файлдаги формула жамидан (218 836,3 млн сўм) кам.
- Маҳалла — D устуни (E устуни бирлаштирилган катак, фарқ бўлса огоҳлантирилади).
- Кучланиш: файл сарлавҳасида AJ = L2, AK = L1, AL = L3.
- ТП тоифаси юкланиш бўйича: 0–50% яшил, 50–60% сариқ, 60% дан юқори қизил.
- Ойлик = кунлик × 30, йиллик = кунлик × 365 (ҳисобланган).
- Фақат тўғри маълумот олинади: бўлиниб кетган ёки рақамларга мос келмаган иш матни рақамлар (G–L) бўйича ёзилади
  (асл матн админ панелда сақланади); манфий/нол кунлик истеъмол ва бўш ТП секциялари олинмайди;
  ТП устунидаги «630» (ГКТП қуввати) ТП рақами ҳисобланмайди.

## Бўлимлар

Бош саҳифа · Туманлар (+ Тошкент жами) · Маҳаллалар (+ жами) · Ишлар · Трансформаторлар · Мақсадлар ·
Ижро (режа/амал) · Таҳлил (бирлик нархлари, подстанциялар, юкланиш, ишдан кейинги ҳолат).
Карточка ёки график устига босилса, у экранда катталашиб очилади (✕ ёки Esc — ёпиш).

## Railway

`railway.json`: `migrate` → `collectstatic` → `import_excel` → `createsuperuser` (ихтиёрий) → `gunicorn`.

Variables:
- `SECRET_KEY` — узун тасодифий матн (мажбурий).
- `DJANGO_SUPERUSER_USERNAME`, `DJANGO_SUPERUSER_PASSWORD`, `DJANGO_SUPERUSER_EMAIL` — админ ҳисоби.
- `ADMIN_PANEL_PASSWORD` — админ панели пароли.
- `DATABASE_URL` — **мажбурий тавсия**: ижро журнали ва юкланган Excel файллар деплойдан кейин ҳам сақланиши учун
  Railway PostgreSQL қўшинг (SQLite ҳар деплойда янгидан яратилади ва киритилган маълумотлар йўқолади).
